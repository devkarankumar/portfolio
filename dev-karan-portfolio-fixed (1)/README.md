## 🌟 Featured Projects

### 1. Multimodal RAG Chatbot
- **Stack:** React, TypeScript, Express, Vite, Google Gemini API
- **Features:** Hybrid search combining dense cosine embeddings with sparse BM25, configurable chunking strategies, multimodal text+image ingestion, and real-time streaming with inline citations.
- **Repository:** [github.com/devkarankumar/rag-chatbot](https://github.com/devkarankumar/rag-chatbot)

### 2. ShopNear Mobile App
- **Stack:** React Native, Expo, Firebase Firestore
- **Features:** Hyper-local discovery engine with adjustable 200m–3km radius radar, dual-portal merchant CMS for live flash offers, and instant deal redemption.
- **Repository:** [github.com/devkarankumar/ShopNearV2](https://github.com/devkarankumar/ShopNearV2)

### 3. Python Voice Assistant
- **Stack:** Python 3, SpeechRecognition, pyttsx3, PyAudio
- **Features:** Hands-free command dispatcher, speech recognition with background noise calibration, and speech synthesis.
- **Repository:** [github.com/devkarankumar/voice-assistant](https://github.com/devkarankumar/voice-assistant)

### 4. WeatherNow Web App
- **Stack:** Python, Django, REST API, OpenWeatherMap
- **Features:** Real-time atmospheric metrics, multi-city forecasts, and responsive UI.

## 🚀 How to Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build
```
